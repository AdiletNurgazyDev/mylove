# Айым + Адлет

Маленький романтичный сайт с нашими фото. Обычная статическая страница: HTML, CSS и JavaScript в одном файле, без сборки и без зависимостей.

## Что внутри

```
index.html   страница сайта
img/         фотографии (подключены обычными ссылками img/имя.jpg)
.nojekyll    чтобы GitHub Pages отдавал файлы как есть
```

## Как открыть у себя

Откройте `index.html` двойным кликом в браузере. Шрифты подгружаются из Google Fonts, поэтому нужен интернет.

## Как выложить на GitHub и получить ссылку

1. Создайте новый репозиторий на github.com, например `aiym-adlet`.
2. Нажмите **Add file → Upload files** и перетащите внутрь `index.html`, `.nojekyll` и папку `img`.
3. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе Source выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через минуту-две сайт будет доступен по адресу `https://ВАШ_НИК.github.io/aiym-adlet/`.

## Как поменять фото и тексты

- Фото: замените файлы в папке `img/` на свои с теми же именами или поправьте пути в `index.html`.
- Тексты: откройте `index.html` в любом редакторе и измените слова внутри тегов `<h2>`, `<p>` и в списке `reasons` в конце файла.
